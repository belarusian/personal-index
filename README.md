# Personal Index

A personal web search engine that scans, filters, and indexes the web based on your defined interests.

## Features

- **Interest Tracking**: Define topics, keywords, and URL patterns to track
- **Web Crawler**: Configurable depth, politeness delays, and rate limiting
- **Local Search Index**: Full-text search with relevance scoring and snippet generation
- **Content Filtering**: Only index content matching your interests
- **Content Tagging**: Automatic topic detection and tagging of indexed content
- **Content Linking**: Find related content items by similarity, domain, and temporal proximity
- **Content Archiving**: Compress and manage old content with gzip/bz2/zstd support
- **Timeline View**: Chronological view of saved content events (day/week/month)
- **Scheduled Crawling**: Periodic re-scanning of tracked topics
- **CLI Interface**: Full command-line interface for all operations
- **REST API**: FastAPI-based server with authentication, rate limiting, and pagination
- **Authentication**: JWT tokens, API keys, password hashing, sessions, and role-based permissions
- **Dashboard**: HTML dashboard with real-time statistics and domain analytics
- **Backup & Restore**: Create, list, and restore backups of your index data
- **Bookmarks**: Bookmark management with HTML, JSON, and OPML export
- **RSS Feeds**: Parse and index RSS/Atom feeds
- **Search Facets**: Filterable search dimensions (domain, date, tags)
- **Search Suggestions**: Autocomplete suggestions based on indexed content
- **Content Annotations**: Add notes, highlights, and ratings to indexed pages
- **Content Scoring**: Priority-based scoring of indexed content
- **Content Deduplication**: Detect and remove duplicate content
- **URL Classification**: Classify URLs by type (article, blog, forum, etc.)
- **Robots.txt Compliance**: Respect robots.txt rules during crawling
- **Sitemap Parsing**: Parse XML sitemaps for efficient crawling
