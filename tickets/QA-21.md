# QA-21: ContentAggregator.merge_all treats falsy ids as missing

Status: OPEN
Issue: #1221

## Symptom
`ContentAggregator.merge_all(deduplicate=True)` uses `item.get("id") or item.get("title")` to build the dedup key. This makes any falsy `id` value (e.g. `""`, `0`) fall back to `title`, so two items that share a falsy `id` but have different titles are not deduplicated.

## Expected per docs
The docstring says: "removes duplicate items keyed on the item's 'id' (falling back to 'title'), keeping the first occurrence." A present `id` value, even if falsy, should be used as the key; only a missing/None `id` should fall back to `title`.
