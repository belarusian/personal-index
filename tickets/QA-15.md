# QA-15: negative-slice "top N" leak — content_summarizer.summarize(max_sentences=-1)

## Symptom
The negative-slice "top N / limit" defect class (QA-1 `extract_top_n`, QA-2
`tfidf`/`index.search`, QA-3 `Feed.get_recent_entries`, QA-4 sweep of 13 sites,
QA-5 sweep of 9 sites — all now CLOSED) has a **NEW public site missed by
QA-5's 9-site sweep**: `content_summarizer.summarize(text, max_sentences=-1)`.

`_score_and_select` does `selected = scored[:max_sentences]` with no negative
guard. A negative `max_sentences` leaks Python negative-slice semantics:
`scored[:-1]` returns **all-but-last** sentences instead of an empty list.
The `0` bound is correct (returns `[]`); the negative bound is not.

Out-of-range (negative) N must yield an empty list, matching the zero guard —
the same contract QA-1..QA-5 established and the implementer has already
applied at every other public "top N" site.

## Affected site (1, confirmed leaking at HEAD)
| module | function | line | idiom |
|--------|----------|------|-------|
| content_summarizer.py | `summarize` (via `_score_and_select`) | 132 | `scored[:max_sentences]` |

A whole-codebase re-sweep of the slicing idiom
(`grep -rnE '\[:[a-z_]+\]' personal_index/`) confirms **content_summarizer is
the only public "top N" site still leaking** — every other site (rss,
progress, content_annotations, content_collections, content_scoring,
search_index, content_recommender, search_suggestions, content_linker,
tfidf, keyword_extractor, content_categorizer, content_digest, cli, cli_top,
formatter, content_export_csv, text_utils, export_markdown, filter/engine,
content_search, index, dashboard/aggregator) is now guarded with
`if <bound> <= 0: return []` (or an equivalent `> 0` ternary). The
dashboard/aggregator negative-limit paths are private helpers only ever called
with their positive defaults, so they are not a public leak.

## Exact repro
    python3 -c "
    from personal_index.content_summarizer import summarize
    text = ('Alpha alpha alpha. Beta beta beta. Gamma gamma gamma. '
            'Delta delta delta. Epsilon epsilon epsilon. Zeta zeta zeta.')
    r = summarize(text, max_sentences=-1)
    print(len(r.sentences), repr(r.summary))
    "

## Observed
    5 'Alpha alpha alpha. Beta beta beta. Gamma gamma gamma. Delta delta delta. Epsilon epsilon epsilon. Zeta zeta zeta.'

## Expected (per docs/content-summarizer.md + the QA-1..QA-5 contract)
    0 ''

`max_sentences=-1` must return a `SummaryResult` with `sentences == []`,
`summary == ""`, `word_count_summary == 0` — exactly as `max_sentences=0`
already does.
