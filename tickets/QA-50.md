# QA-50: `URLValidator.validate()` crashes (AttributeError) on non-string input

Status: OPEN
Issue: #1634
Component: `personal_index/validator.py` (`URLValidator.validate` line 58 — `if not url or not url.strip():` at line 62 and `url = url.strip()` at line 65 call `.strip()` on the raw value with no type guard)
Refs: `URLValidator.validate` docstring ("Run length, scheme, domain, path and fragment checks"); the module is a public validation utility whose contract implies robust handling of malformed input
Deep test: tests/deep/test_validator_adversarial.py (TestURLValidatorNonString — test_int_input_does_not_crash, test_float_input_does_not_crash, test_list_input_does_not_crash — all xfail-strict)

## Symptom

`URLValidator.validate(url)` is documented as a validation entry point and is
expected to return a `ValidationResult` (with `valid=False` and an error
message) for malformed input. But for any non-string input it raises
`AttributeError` instead of returning a result:

    >>> URLValidator().validate(123)
    AttributeError: 'int' object has no attribute 'strip'

The `None` and empty-string cases are handled (they short-circuit to
"URL is empty"), but `int`, `float`, `list`, `bytes`, etc. reach
`url.strip()` and crash. A validator that crashes on the very inputs it is
meant to validate is a contract violation: callers cannot distinguish a
validation failure from an unhandled exception.

## Repro

    from personal_index.validator import URLValidator

    for bad in (123, 3.14, ["a"]):
        try:
            URLValidator().validate(bad)
            print("no-crash", repr(bad))
        except AttributeError as e:
            print("CRASH", repr(bad), e)

    # -> CRASH 123 'int' object has no attribute 'strip'
    # -> CRASH 3.14 'float' object has no attribute 'strip'
    # -> CRASH ['a'] 'list' object has no attribute 'strip'

## Expected

`validate` should return `ValidationResult(valid=False, errors=[...])` for
non-string input (e.g. "URL must be a string"), not raise.

## Fix

Guard the input type at the top of `validate`:

    if not isinstance(url, str):
        result.add_error("URL must be a string")
        return result
