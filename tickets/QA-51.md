# QA-51: `ContentValidator._is_mostly_whitespace()` only counts spaces, so tab/newline-heavy content that is effectively whitespace is not flagged

Status: OPEN
Issue: #1635
Component: `personal_index/validator.py` (`ContentValidator._is_mostly_whitespace` line 174 — `whitespace_ratio = content.count(" ") / len(content)` counts only the SPACE character, not `\t`/`\n`/`\r`/other whitespace)
Refs: `ContentValidator.validate` docstring ("error for empty or mostly-whitespace content"); `ContentValidator._is_mostly_whitespace` docstring
Deep test: tests/deep/test_validator_adversarial.py (TestContentValidatorTabWhitespace — test_tab_heavy_content_flagged, test_newline_heavy_content_flagged — both xfail-strict)

## Symptom

`_is_mostly_whitespace` is meant to flag content that is "mostly whitespace"
as an ERROR (invalid). But it computes the whitespace ratio as
`content.count(" ") / len(content)` — counting only the literal SPACE
character. Content that is overwhelmingly TAB or NEWLINE characters is
therefore NOT flagged, even though it is effectively whitespace and should
be rejected.

    >>> ContentValidator().validate("a" + " " * 200).valid
    False   # space-heavy -> correctly flagged
    >>> ContentValidator().validate("a" + "\t" * 200).valid
    True    # tab-heavy -> NOT flagged (defect)
    >>> ContentValidator().validate("a" + "\n" * 200).valid
    True    # newline-heavy -> NOT flagged (defect)

The `content.strip()` guard at the top of the method only catches content
that is ENTIRELY whitespace; a single non-whitespace char plus 200 tabs
passes the strip guard and then the space-only ratio is ~0, so no error.

## Repro

    from personal_index.validator import ContentValidator

    c = ContentValidator()
    print(c.validate("a" + " " * 200).valid)   # False (space-heavy flagged)
    print(c.validate("a" + "\t" * 200).valid)  # True  (tab-heavy NOT flagged)
    print(c.validate("a" + "\n" * 200).valid)  # True  (newline-heavy NOT flagged)

## Expected

Tab- and newline-heavy content that is effectively whitespace should be
flagged as an error (valid=False, "Content is mostly whitespace"), matching
the space-heavy behaviour.

## Fix

Count all whitespace, e.g. `sum(ch.isspace() for ch in content) / len(content)`,
instead of `content.count(" ")`.
