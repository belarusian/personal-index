# QA-76 — ContentMerger concatenate injects a phantom separator for whitespace-only sources

- **Status:** CLAIMED 2026-09-18
- **Issue:** #1792
- **Role:** validator (filed cycle 368)
- **Severity:** medium (contract violation; corrupts merged output with stray `---` separators)
- **Owner path:** personal_index/content_merger.py (implementer)
- **Deep test:** tests/deep/test_content_merger_adversarial.py::TestMergeConcatPhantomSeparator::test_concatenate_whitespace_only_source_injects_phantom_separator (xfail-strict, links this ticket)

## Symptom
`ContentMerger(strategy="concatenate").merge([...])` promises (per the `merge()`
docstring) to "join **non-empty** content with a `\n\n---\n\n` separator".
`_merge_concatenate` guards with `if source.content:` — truthy on the **raw**
string — so a whitespace-only source such as `"   "` passes the guard, is then
`.strip()`-appended as the empty string `""`, and injects a **phantom separator**
between the real contents.

## Exact repro
    python3 -c "
    from personal_index.content_merger import ContentMerger, MergeSource
    def s(c): return MergeSource(url='u', content=c)
    r = ContentMerger(strategy='concatenate').merge([s('A'), s('   '), s('B')])
    print(repr(r.content))
    print('separator count:', r.content.count('---'))
    "

## Actual (on main 9eb19a85)
    'A\n\n---\n\n\n\n---\n\nB'
    separator count: 2

Two `---` separators and an empty paragraph between them, for two non-empty
sources. The whitespace-only source produced a phantom `---` block.

## Expected per docs
The `merge()` docstring states concatenate "joins **non-empty** content with a
`\n\n---\n\n` separator". A whitespace-only source is empty after `.strip()`,
so it must be skipped entirely:
    'A\n\n---\n\nB'
    separator count: 1

## Traceback
No exception — silent output corruption. The defect is the extra separator.

## Root cause (for the implementer; validator does NOT fix)
`_merge_concatenate` at personal_index/content_merger.py uses `if source.content:`
(raw-truthy). The fix is to test the stripped value, e.g.
`stripped = source.content.strip(); if stripped: contents.append(stripped)`.
The existing `test_merge_all_empty_content_concatenate` masks this by only
testing the all-empty case; the mixed real+whitespace case above is the clean
repro.
