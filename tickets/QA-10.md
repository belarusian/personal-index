# QA-10: link_analyzer.get_aggregate_stats — unique_external_domains undercounted beyond top-20

## Symptom
`LinkAnalyzer.get_aggregate_stats` computes `unique_external_domains` from the
**top-20-truncated** `stats.domain_distribution` keys:

    all_domains: set[str] = set()
    for r in results:
        all_domains.update(r.stats.domain_distribution.keys())
    ...
    "unique_external_domains": len(all_domains),

But `stats.domain_distribution` is capped at the top 20 domains
(`dict(domain_counter.most_common(20))`), while the per-page
`stats.unique_domains` holds the **full** distinct count
(`len(domain_counter)`). So whenever a page has more than 20 distinct
external domains, the aggregate `unique_external_domains` undercounts:

- 25 distinct external domains on one page -> `stats.unique_domains == 25`
  but `get_aggregate_stats([r])["unique_external_domains"] == 20`.
- 50 distinct -> aggregate reports 20.

The aggregate should report the true distinct external-domain count, not the
top-20 window.

## Affected site
| module | function | line | idiom |
|--------|----------|------|-------|
| link_analyzer.py | `LinkAnalyzer.get_aggregate_stats` | ~137-140 | `all_domains.update(r.stats.domain_distribution.keys())` (top-20 truncated) |

## Exact repro
    python3 -c "
    from personal_index.link_analyzer import LinkAnalyzer
    a = LinkAnalyzer(base_domain='example.com')
    links = [{'url': f'http://d{i}.com/x', 'text': 't'} for i in range(25)]
    r = a.analyze('http://example.com/', links)
    print('per-page unique_domains      :', r.stats.unique_domains)
    print('domain_distribution len      :', len(r.stats.domain_distribution))
    print('aggregate unique_external    :', a.get_aggregate_stats([r])['unique_external_domains'])
    "

## Observed output
    per-page unique_domains      : 25
    domain_distribution len      : 20
    aggregate unique_external    : 20

The aggregate reports 20 distinct external domains when the page actually has
25.

## Expected per docs/contract
`get_aggregate_stats` docstring: "Get aggregate statistics across multiple
analyses." The `unique_external_domains` field must reflect the true number of
distinct external domains across the analyzed pages (consistent with the
per-page `stats.unique_domains`), not the top-20 truncated window.
