# QA-13: ThrottleManager._extract_domain() is not a true domain extractor; rate_per_second crashes on zero window

Status: OPEN
Priority: medium
Component: personal_index/throttle.py
Filed: Cycle 172
Issue: #1175

## Summary

`ThrottleManager` is documented as "per-domain rate limiting" (module docstring:
"Request throttling with per-domain rate limiting"), but its domain key is the
raw `urlparse(url).netloc`, which is not a normalized domain. This lets a
crawler bypass the per-domain rate limit by varying the hostname form, and a
degenerate rule crashes.

1. **Case-sensitive domain key**: `EXAMPLE.com` and `example.com` are the same
   DNS domain but map to different throttle buckets. A crawler can double its
   effective rate by alternating hostname case.

2. **Port included in domain key**: `example.com:8080` and `example.com` are
   the same domain (the port is not part of the domain) but map to different
   buckets.

3. **Userinfo not stripped**: `user:pass@example.com` yields the key
   `"user:pass@example.com"` instead of `"example.com"`.

4. **rate_per_second ZeroDivisionError**: `ThrottleRule(max_requests=10,
   window_seconds=0.0).rate_per_second` raises `ZeroDivisionError` (no guard
   for the degenerate zero-window case).

## Repro

    python3 -c "
    from personal_index.throttle import ThrottleRule, ThrottleManager
    m = ThrottleManager()
    print(repr(m._extract_domain('http://EXAMPLE.com/')))        # 'EXAMPLE.com'
    print(repr(m._extract_domain('http://example.com/')))        # 'example.com'  -> different bucket
    print(repr(m._extract_domain('http://example.com:8080/')))   # 'example.com:8080'
    print(repr(m._extract_domain('http://user:pass@example.com/')))  # 'user:pass@example.com'
    print(ThrottleRule(max_requests=10, window_seconds=0.0).rate_per_second)  # ZeroDivisionError
    "

## Expected per docs

- Module docstring: "Request throttling with **per-domain** rate limiting."
  DNS domains are case-insensitive and do not include the port or userinfo, so
  all four hostname forms above must map to the same throttle bucket.
- `rate_per_second` property: "Requests allowed per second (max_requests /
  window_seconds)." A zero window is a degenerate input that should not raise
  an uncaught `ZeroDivisionError`.
