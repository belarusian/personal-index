## Symptom

`truncate_text(text, max_length=N)` with a NEGATIVE `N` leaks Python
negative-slice semantics instead of yielding the same result as the zero
bound (`N == 0`). Per `docs/CONTRACTS.md` the Negative-slice guard (binding)
requires a non-positive caller-supplied bound to yield the same empty/zero
result as the zero bound; a negative bound must NOT leak `list[:-N]`
(all-but-last-N) semantics.

## Root Cause

In `personal_index/text_utils.py:50` (`truncate_text`), the guard is:

    if not text or len(text) <= max_length:
        return text or ""

A negative `max_length` (e.g. -5) does NOT trip `len(text) <= max_length`
for any non-empty text (len >= 0 > -5), so execution falls through to:

    truncated = text[:max_length]

With `max_length = -5`, `text[:-5]` is a NEGATIVE SLICE (all-but-last-5
characters), not an empty prefix. The function then appends the suffix,
returning a near-full copy of the input instead of the zero-bound result.

## Repro

    from personal_index.text_utils import truncate_text
    text = "hello world this is a test"
    print(truncate_text(text, 0))    # '...'          (zero bound: text[:0] = '')
    print(truncate_text(text, -5))   # 'hello world this is...'  (NEGATIVE SLICE text[:-5])
    print(truncate_text(text, -1))   # 'hello world this is a...' (NEGATIVE SLICE text[:-1])

    # The negative-slice leak:
    print(text[:-5])                 # 'hello world this is a'  <- what text[:-5] is

## Expected per docs / contract

`docs/CONTRACTS.md` Negative-slice guard (binding): "A non-positive `N` is
out-of-range and must yield the same empty result as the zero bound; a
negative `N` must NOT leak Python negative-slice semantics (`list[:-1]` =
all-but-last). The guard short-circuits BEFORE the slice."

Minimal fix: guard `max_length <= 0` BEFORE the slice, returning the same
result as `max_length == 0` (i.e. `"" + suffix` or `text or ""` depending on
the zero-bound contract). E.g.:

    if not text:
        return ""
    if max_length <= 0:
        return suffix          # or: return (text or "")[:0] + suffix
    if len(text) <= max_length:
        return text
