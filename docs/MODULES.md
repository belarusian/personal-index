# Module Documentation

## Core Modules

### `personal_index.models`

Core data models for the application.

**Key Classes:**
- `Interest` - User-defined interest with keywords, URL patterns, and priority
- `CrawlConfig` - Web crawler configuration (depth, delay, rate limit)
- `SearchResult` - Search result with relevance score and snippet
- `Page` / `IndexedPage` / `CrawledPage` - Page data models
